Descripción del proyecto

Este repositorio contiene el código fuente y los recursos desarrollados durante la realización del Trabajo de Fin de Grado.

El proyecto está compuesto por dos partes principales:

Python: scripts desarrollados para el procesamiento, análisis y tratamiento de los datos.

Android (Kotlin): aplicación móvil desarrollada mediante Android Studio.

Instalación y ejecución

Python

Descargar o clonar este repositorio.

Instalar las dependencias necesarias.

Ejecutar los scripts correspondientes.

Android

Abrir Android Studio.

Seleccionar la carpeta del proyecto Android.

Esperar a que se complete la sincronización de Gradle.

Ejecutar la aplicación en un dispositivo o emulador compatible.
