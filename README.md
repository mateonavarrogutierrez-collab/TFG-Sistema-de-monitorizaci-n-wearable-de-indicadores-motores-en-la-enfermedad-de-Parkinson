Descripción del proyecto

Este repositorio contiene el código fuente y los recursos desarrollados durante la realización del Trabajo de Fin de Grado.

El proyecto está compuesto por dos partes principales:

Python: scripts desarrollados para el procesamiento, análisis y tratamiento de los datos.

Android (Kotlin): aplicación móvil desarrollada mediante Android Studio.
